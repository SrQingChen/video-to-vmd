### 1.1 与最初“渲染比对闭环”的关系

最初设想是：

```
视频 → VMD → 渲染目标模型当前帧 → 和视频当前帧比较 → 改深度/位置/角度 → 再输出 VMD
```

这是运行时 **analysis-by-synthesis / render-and-compare 闭环**。当前 M3.5 不是这个：

- 当前是 **one-shot**：证据 → 一次网络前向 → 应用有界残差 → QC/回退 → VMD；
- 推理时**不重新渲染目标模型、不和原视频做像素/剪影比较**；
- 训练时才用 GT 算残差；运行时没有 GT。

为什么没有直接做原设想：

1. **跨身份像素/剪影不可比**：视频角色/真人和 PMX 的外观、衣服、头发、体型不同；
   像素差异会把“服装/体型差”优化成姿态错误；
2. **相机/深度不可观**：单目下不同深度可以投影成同一 2D；渲染对比本身不产生深度证据；
3. **运行时渲染闭环代价高且会振荡**：每帧渲染+优化容易在深度/roll 上抖动。

M6 要做的是**结构闭环**，不是回到像素闭环：

```
应用 VMD → 用目标骨架/相机投影出 2D 关节/肢体/接触 → 和源证据比较
→ 生成低维残差 → 再应用（2–3 轮）→ 稳定性/接触/穿透门控
```

- 比较的是 2D 关节/肢体方向/部件/接触/时序，不是 RGB/剪影；
- 可选的 target render 只用于**目标空间约束/QC**（穿透、接触、取景），不作为主 loss；
- 像素/剪影只在同身份/合成 GT 的教师/基准里使用，不用于跨身份运行时；
- 如果多轮没有稳定增益，保留 one-shot，并明确命名“学习式残差后馈”，不冒充闭环控制器。

### 1.2 研究依据与缺口（必须诚实）

当前 M6 方向的依据分两类：

**有依据的部分**：

- 数据不足是实测瓶颈：train 手 L0/L1 只有 462 帧、T5 L0/L1 8.3%/1.7%；
- 收益集中在躯干：chest 43.67→16.10，upperarm/forearm 只有 −1～−2°；
- full 档 T5 jerk +15.2%、手指 p95 2.83；
- 教师受 clavicle 60° 界裁剪；
- 接触/脚滑/根必须与 contact IK 联合；
- 残差学习、接触感知重定向、analysis-by-synthesis 都有文献先例
  （NKN/SAN/M-R²ET/ReConForM/UnderPressure/CycleAdapt 等）。

**还没有充分依据的部分**：

- 没有做 2024–2026 的系统 SOTA 扫描（视频→动作、重定向、测试时适应、手/脸、
  接触感知、残差反馈）；
- 没有先 benchmark 现成的新方法，就计划自己比较 BiGRU/TCN/Transformer/Graph；
- 架构选择目前是假设，不是“文献证明在这个任务上最好”；
- 手/脸 full 后馈和真实配对数据的能力边界未验证。

因此 M6 必须加一个 **M6.0 研究/benchmark gate**，先调研/试现成方法，再决定是否自研：

1. 检索并筛选 2024–2026 的相关工作：单目人体动作/重定向、测试时适应、
   接触/脚滑、手/脸、残差反馈；优先有代码、权重、许可、8GB 可跑；
2. 对 1–2 个最强候选做小样本 benchmark（R3 留出 + T5 视觉），
   与当前 M3.5 默认逐项比较；
3. 如果现成方法在数据/教师/架构/手脸上明显更好，优先复用/改造；
   没有明显收益再按本计划自研；
4. 产出 `docs/M6.0_研究调研与benchmark.md`；**没有完成 M6.0 不开始大规模训练。**

已知负结果（不要重复）：VPoser v2 与 R2 GT 反相关；Multi-HMR 在 R2/T5 全面更差；
2D/多视/BA 到不了手臂 10°。这些是 M6.0 的对照基线，不是“再试一次”的理由。

## 2. M6 目标

### 2.1 数据扩展

- 在现有 43 段基础上扩到至少 **2–4× 帧数/段数**（质量优先，不设上限）：
  - 更多动作：AMASS/CMU 或用户提供的授权动作；R1/R2/R3 的时间缩放、镜像、根 yaw；
  - 三模型 × 三机位；新增相机扰动/近景手/脸机位（只训练泛化，评估固定机位）；
  - 遮挡/丢帧/压缩/低分辨率增强（只改观测侧）；
  - 真实配对数据（如果有）单独作为域验证，不与合成混合评估。
- 手/脸数据：
  - 手：合成手近景/GT 手指，或 MANO/WiLoR 产生的 L0/L1；L2/L3 fallback 不作监督；
  - 脸：L0 blendshape/合成表情；L1 只 blink；缺的通道 support mask=0；
  - 目标：把 train 手 L0/L1 从 462 帧提高到至少 3–5k 帧；否则手网络仍会学成“默认微屈”。
- split 仍按动作/模型/机位整段；R3 不参与训练/调参；T5 只做无 GT 验收。

### 2.2 教师增强

- 保留“结构教师 + GT”，不用像素/剪影；
- 当前 60° clavicle 界是主要瓶颈：评估 **世界空间肩/上臂残差**、分层肩链、
  或更大有界残差；必须检查穿透/脚滑/T5；
- 腿/髋仍交给 contact IK；根 XZ 与 contact 联合求解后再评估，不默认开；
- 教师可达性报告：每个 clip 的 teacher after、网络 after、差距原因；
- 不用弱教师固化错误；教师不稳先修规则/数据。

### 2.3 网络增强

- Baseline：2.10M BiGRU；比较：
  - TCN/Transformer/Graph 时序模型（2–10M，8GB）；
  - per-factor heads（root/body/hands/face）、target-profile conditioning、
    uncertainty/confidence 输入、multi-hypothesis（谨慎）；
  - 因果/流式版本（lookahead 0.3–0.5s）与离线双向版本；
- 训练目标：masked Huber + body-relative/3D + contact + temporal/jerk + penetration；
  不用像素/剪影；残差有界；
- **闭环/多轮反馈是 M6 的明确实验项**：当前 M3.5 是“一次前向 → 应用残差”的 one-shot
  refiner，不是控制意义上的闭环。M6 至少实现并评估 **2–3 轮 residual pass**
  （apply → 重新计算证据/目标约束 → 再预测），验证增益；没有增益就保留 one-shot，
  并在文档里明确称“学习式残差后馈”而不是“闭环控制器”。
- 不允许直接回归 53 骨四元数；保持低维、可解释因子；
- 过拟合检查：按动作/模型/机位留出；T5 只视觉。

### 2.4 Full 后馈（手/脸/根/肩臂）

- 手/脸：在扩展数据上重训；只在 L0/L1/合成 GT 上监督；T5 手指/morph 步长门禁；
- 根：与 contact IK 联合，先离线求解，再评估脚滑；不单独开根 XZ；
- 肩臂：世界空间残差/更大肩界；目标 upperarm/forearm 组明显改善，不只 chest；
- secondary：world/position 不劣化（至少不超过当前 +1.65°/+0.141%H）；
- 只有全部过门禁才设默认；否则保留 `feedback v1` 保守档。

### 2.5 评测与集成

- 留出 R3 + val + 合成 GT；T5 无 GT；真实视频（如有）单独报告；
- 与 M3.5 默认逐项对比：main、chest/upperarm/forearm、contact、jerk、secondary；
- 消融：数据/教师/架构/factor 各自贡献；
- 新 checkpoint `feedback v2`，`--feedback v2`；M4 管线可切换；
- 不达标不默认；不改 M5 长视频/发布逻辑。

## 3. 工作量与顺序

| 包 | 占比 | 内容 |
|---|---:|---|
| **M6.0 研究/benchmark** | **10%** | 2024–2026 相关工作、1–2 个候选小样本对比；决定复用/自研 |
| 数据扩展 | 30% | 动作/模型/机位/增强、手/脸近景、split/泄漏审计 |
| 教师/因子 | 20% | 肩世界空间、根+contact、手/脸监督边界、可达性 |
| 网络/训练 | 25% | one-shot vs 2–3 轮、BiGRU vs TCN/Transformer/Graph、per-factor |
| 评测/集成 | 15% | 留出/T5/真实、消融、默认决策、M4 切换 |

顺序：

1. **先做 M6.0**：调研 + 小样本 benchmark；没有完成不开始大规模训练；
2. 再扩数据 + 泄漏审计；没有数据不要先换大模型；
3. 再修教师可达性（肩/根/手脸）；
4. 再比较网络/多轮；最后做 full/default 决策；
5. 任何阶段没通过，保留 M3.5 默认档，不硬上。

## 5. 需要准备

- **优先**：更多授权动作数据（AMASS/CMU/自有）；真实配对数据可选；
- **手部**：MANO 官方权重/WiLoR/HaMeR（可选；没有则用合成手近景/现有 L0/L1）；
- **真实视频**：M7 用；M6 不强制；
- 8GB 显存：小模型/梯度累积/半精度；质量优先可慢。

## 6. 不要做

1. 不要只把网络变大/训练更久而不同时扩数据/修教师；
2. 不要把 full/根/手/脸直接设默认；
3. 不要用 T5 训练/调参；
4. 不要用像素/剪影作主 loss；
5. 不要用腿/髋覆盖 contact IK；根 XZ 必须与 contact 联合；
6. 不要隐藏 secondary、回退、失败消融；
7. 不要为了 RTF 牺牲质量；不 commit/不公开，除非明确说。
