## 2. 检索范围与方法

检索时间：2026-10-28。关键词覆盖：

- 单目视频人体动作/网格恢复：GVHMR、WHAM、TRAM、PromptHMR、SMPLest-X、CameraHMR、Multi-HMR、ScoreHMR；
- 重定向：GMR（Retargeting Matters）、ReConForM、HybrIK、MoCapAnything；
- 测试时适应/测试时训练：CycleAdapt、STRIDE、HTD-Refine；
- 接触/脚滑：UnderPressure、FootMR、ExMR、PhySIC、PICO；
- 手/脸：HaMeR、WiLoR、SMPLest-X、ExMR/HandMR；
- 残差/时序修正：SmoothNet、SynSP、MotionRefineNet、SMRNet、HTD-Refine。

筛选标准（按顺序）：

1. 是否解决“已有 HMR 输出的结构残差/重定向/接触/手脸”问题，而不是另一个端到端 HMR；
2. 是否有公开代码和可下载权重；
3. 许可是否允许研究使用/改造；
4. 8GB 显存能否推理；
5. 能否映射到本项目的 canonical/PMX/VMD 与 R3/T5 评测。

> 本机网络事实：`github.com`/`raw.githubusercontent.com` 直连超时；`gh api` 可用；
> HuggingFace、Google Drive 不可达；`download.is.tue.mpg.de` 可达但需要账号。
> 这直接排除了大多数 2024–2026 候选的权重。

### 3.1 为什么没有选 MotionRefineNet/HTD-Refine 做完整 benchmark

- MotionRefineNet 只发布代码，不发布与本项目匹配的权重；其训练依赖 SmoothNet 的数据预处理（Google Drive）和 AIST/3DPW 等数据集。把它直接在我们的 R1/R2/R3 上训练，属于“架构对比”，不是“现成方法 benchmark”，放在 M6.3 与 BiGRU/TCN/Transformer/Graph 一起做更合适。
- HTD-Refine 的核心增益来自 PVA-Net 的视频速度/加速度目标；没有 `pvanet.pt` 就无法复现。只跑其优化阶段会退化成“用自己的动力学平滑自己”，不能代表该方法。
- FootMR/ExMR 代码未发布；但它的结论（GVHMR + 残差 ankle/hand refiner）与 M6 计划一致，作为方向依据。
- 这些方法都已在本文档记录“为什么不可运行”，不把“没跑”说成“跑过且更差”。

## 4. Benchmark 协议

### 4.1 数据与基线

- **R3 留出**：整段未见（M3.5 test），三模型 × 三机位 9 段；小样本用 `si` 的 front / three_quarter / side 三段。
- **T5 无 GT**：真实动漫舞蹈 242 帧；只做稳定性/脚滑/视觉，不冒充精度。
- **基线**：`cleanup+ik`（M3.5 的 `pred/ik.vmd`），以及 **M3.5 默认档**（torso .85 / arm .2 / smooth 3；手/脸/根关）。
- 指标：`body_relative_main`、chest/upperarm/forearm 组、world angle、position、contact recall/slide/penetration/height、jerk。

### 4.2 候选 A：GVHMR flip-TTA

实现：`scripts/m60_flip_tta.py`
1. 用 ffmpeg 水平镜像渲染视频；
2. 在镜像视频上重跑 GVHMR；
3. 按 GVHMR 官方 flip test：`flip_smplx_params` 翻回 + `avg_smplx_aa` 平均 **incam body_pose/betas**；
4. 保留原 global root orientation/translation（官方 flip test 不平均 global orientation；混合 global/incam 会产生 ~90° 根 yaw 错误）；
5. 同一 adapter → cleanup → contact IK → 评分。

### 4.3 候选 B：UnderPressure

实现：`scripts/m60_underpressure.py`
- 用 GVHMR SMPL-X 关节近似映射到 UnderPressure 的 23 关节（spine_4 复用 chest；左右按 SMPL-X 索引）；
- Y-up → Z-up，30→100 fps 线性重采样；
- `DeepNetwork.contacts` 输出每脚接触；
- 与 GT 脚高接触（同一 2% 身高阈值）比较 precision/recall/F1；
- 基线是预测脚高的同一阈值。

| chest group | 41.19° | 40.37° | −0.82° |
| upperarm group | 28.99° | 26.06° | **−2.93°** |
| forearm group | 42.97° | 38.29° | **−4.69°** |
| world angle | 68.80° | 68.26° | −0.54° |
| position | 8.374%H | 8.268%H | −0.106%H |
| contact recall | 0.1667 | **0.0714** | **−0.095** |

| contact height MAE | 1.803%H | 1.965%H | +0.162%H |

### 5.2 flip-TTA → M3.5 默认档（R3 si 三机位）

| 片段 | baseline M3.5 | flip-TTA + M3.5 | Δ |
|---|---:|---:|---:|
| R3_si_front | 25.36° | **24.46°** | −0.90° |
| R3_si_three_quarter | 25.17° | 25.51° | **+0.34°** |

- **three_quarter 不退反进**，所以不能无门禁地设为默认；side 的 −8.69° 说明它对“侧视手臂深度”有真实信息。

| 指标 | UnderPressure | 高度阈值基线 | GT |
|---|---:|---:|---:|
| mean F1 | 0.0399 | 0.0399 | — |
| mean recall | 1.000 | 1.000 | — |

## 6. 决策

### 6.1 不复用现成方法作为主 refiner

- flip-TTA 单独：34.91° > 27.38°，且接触变差；
- flip-TTA + M3.5：平均改善，但 three_quarter 退化、position 变差；不符合“by model/view 全改善”；
- UnderPressure：本域退化；
- 其它候选：权重/代码/许可/显存不可行。

### 6.2 复用的具体部分

| 来源 | 复用方式 |
|---|---|
| GVHMR flip test | M6 可选上游 `flip_tta` 输入/多假设；不作为默认，除非 v2 在全部 R3 机位过门禁 |
| MotionRefineNet | v2 增加 `arch="mrn"`：时序 TCN + 长度无关的频域分支（共享 per-bin MLP），与 BiGRU/TCN/Transformer 同数据对比 |
| HTD-Refine | 多轮 residual pass 的“apply→重算证据→再预测”；根/contact 联合；不引入 AGPL 代码 |
| FootMR/ExMR | 确认“在 GVHMR 上做低维残差”的方向；v2 保留手/脚低维因子，不做全 53 骨回归 |
| GMR | rest-pose 对齐/局部缩放思想已在 adapter；不引入 robot IK |
| UnderPressure | 不采用；脚接触仍由 M2.2 contact IK + 几何/速度门控负责 |
| SynSP / CycleAdapt / STRIDE | 只作为“时序质量线索/循环自监督/测试时训练”的设计依据；不引入代码/权重 |

### 6.3 M6 实施顺序（本文件之后）

1. **M6.1 数据扩展**：现有 43 段 + 前左视角（训练专用）+ lowres/blur 观测增强 + 合成手 L0/L1 + 合成脸 L0；目标 2–4× 帧、手 L0/L1 ≥3–5k；R3 整段留出不变。
2. **M6.2 教师**：`ROT_BOUND_V2`（clavicle 120°/upperarm/forearm 150°）；R3 教师可达 **2.34→0.06°**（v1→v2，9 段平均），0 个因子被裁剪；根+contact 联合作为消融。
3. **M6.3 网络/闭环**：v2 特征 289 维（追加基线手/脸）；BiGRU vs TCN/Transformer/MRN/Graph；per-factor heads；one-shot vs 2 轮 residual pass；先离线，再因果。
4. **M6.4 评测/集成**：留出 R3 门禁（main ≤27.38°、by model/view 全改善、chest/upperarm/forearm 至少两项改善、contact/jerk/secondary 不劣化）；T5 手指/morph 步长；`--feedback v2` 可切换；不达标保留 M3.5 默认。
