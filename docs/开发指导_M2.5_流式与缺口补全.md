## 3. 架构

### 3.1 状态

```
s_t = (canonical_pose_t, velocity_t, contact_t, phase_t, uncertainty_t, confidence_t)
```

- 输入：当前管线的 canonical/VMD 姿态；per-frame confidence（2D/接触/遮挡）；
- 输出：流式 VMD 帧 + 置信度；离线模式可二次精修。

### 3.2 v0：无训练基线（先做）

先不要训网络。用经典因果状态机：

1. 高置信帧：直接采用当前前馈/cleanup 输出；
2. 中置信帧：用 **AR/常数速度 + 关节限位** 预测，和当前观测做置信度加权融合；
3. 低置信/漏检帧：保留上一帧速度/相位/接触，rollout **有界**（例如 ≤0.5–1s），不要无限外推；
4. 接触/相位：脚接触状态延续；相位用运动速度/周期估计，缺失时不强行造节拍；
5. 边界混合：lookahead 0.3–0.5s；重叠窗口 + 速度/加速度匹配；不硬切；
6. 离线精修：以流式输出为初始化，做双向窗口优化/清理；最终 VMD 可用离线结果。

**v0 目标**：在 10–30% 随机丢帧/遮挡下，动作不冻结、不跳变；实现简单、可解释。它可能不够自然，但作为 baseline 和门禁。

### 3.3 v1：小型运动先验（v0 不够再做）

- 小型 GRU/VAE（1–5M 参数）在 canonical 姿态序列上训练；输入姿态/速度/接触/相位，输出下一帧分布；
- 数据：R1/R2/R3 重定向到 canonical + 合成扰动/丢帧 + 可选 AMASS（未下；先不用）；
- 推理：置信度高时用观测，低时用 prior；采样时用温度/不确定性控制，不要过度随机；
- 这是 **运动先验**，不是后馈残差网络；不要用它替代证据/教师；
- 8GB 可训/可跑；训练前先只用 R1/R2/R3，数据不足就保持 v0，不要硬训。

### 3.4 流式 vs 离线

- 流式：固定 lookahead，因果状态；用于预览/长视频/交互；允许略低质量；
- 离线：双向窗口 + 全局根/接触一致性 + cleanup；最终交付用离线；
- 两者共享状态/先验/接触逻辑；不要维护两套完全不同的管线。

## 4. 数据与评测

### 4.1 合成 GT

- R2/R3 三机位（已有 `outputs/synth/si_R2_fixed` 等）；GT VMD；
- 人为制造：
  - 随机丢帧 10/20/30%；
  - 连续遮挡段 0.3–1.5s；
  - 2D 置信度降低/关键点抖动；
  - 根轨迹短缺口。
- 对比：baseline（不补）、v0、v1；GT 只读评分。

### 4.2 指标

- 缺口段：关节角/3D 位置误差 vs GT；
- 边界：速度/加速度/jerk 突变；接触断裂；
- 连续性：是否冻结、是否跳变、恢复时间；
- 接触：recall/precision/slide/penetration（不劣化）；
- 视觉：T5/T1/T2 并排；无 GT，只做人工/自检；
- 运行：流式延迟（lookahead）、离线耗时。

### 4.3 门禁（建议）

- 20–30% 丢帧下：无冻结/无 >阈值跳变；边界 jerk 不高于 baseline 太多；
- 缺口段误差不高于“直接保持上一帧”的 baseline（v0 至少要赢这个）；
- 接触 recall/slide/penetration 不劣化；
- 真实 T5 视觉连续，无明显“机器人停顿/瞬移”；
- 不改变手臂/身体默认质量；不引入新的穿模。
