## 2. M2.2：接触 + 腿 IK（最高优先）

### 2.1 目标

- 前视接触召回 **0.46 → ≥0.70**；
- 接触区间滑动不升（side 已有 2.80→0.74；front 0.33 不升）；
- 穿地不增；
- 不靠压 root/脚高“假装着地”；非接触帧保留真实抬脚/跳跃。

### 2.2 输入

- canonical/VMD（当前 23 身骨 FK）；
- PMX 目标腿链（足/ひざ/足首/つま先）+ 腿长；
- 接触证据：
  - 预测 toe/foot 高度、水平/垂直速度；
  - 2D 脚踝/脚尖关键点置信度；
  - 可选：深度/地面、GT 接触（仅合成评测，不用于 T5 清理）。
- 现有 `src/vtv/cleanup.py` 的接触检测（高度带 + 速度 + 迟滞）先作为基线；不要直接用它锁死。

### 2.3 算法

1. **接触概率**：每只脚输出 `p_contact ∈ [0,1]`，由高度带、速度、2D 置信度、时序迟滞组成；不要用单一阈值。
2. **仅在可信区间做 leg IK**：
   - 2-bone IK（hip→knee→ankle），膝盖平面取当前帧 hip-knee-ankle 平面；保持髋/上身不变；
   - 目标：接触帧脚踝/脚尖到地面高度带内；非接触帧不强制；
   - 关节限位：膝盖不能反折；髋/膝/踝限位；
   - 修正幅度 trust region：单帧膝关节 ≤10–15°，累计位移 ≤2–3% 身高；超限只报告不改。
3. **root 只做 XZ 补偿**（可选）：接触区间脚被拉走时，小幅移动 root XZ；不平移 Y 来“压地”；总位移 cap 2 unit，5 帧平滑。
4. **优先级**：leg IK 修接触点 → root XZ 小补偿 → 不做全局平滑；不写 IK 骨到 VMD（保持 IK off + FK 腿）。
5. **门控**：`p_contact < 0.8` 不锁；front/3-4 当前预测接触不可信（0.46/0.70），先用 IK 改善脚高/接触，再决定是否锁；side 0.98 可锁。
6. **不掩盖前馈**：如果 IK 需要 >15° 膝修正才能着地，说明前馈腿长/脚高错，报告并保留原姿态；不要硬压。

### 2.4 评测

- 合成 GT（R2/祀，三机位）：接触 recall/precision、净滑动、穿地、foot height MAE、膝/髋限位、骨长；目标 front recall ≥0.70，slide 不升，penetration 不升。
- 真实 T5：无 GT，只做 foot-lock 自检（jerk/脚高/穿地/接触比例）+ 人工抽查；不声称精度。
- 新增/修改：
  - `src/vtv/contact_ik.py` / `scripts/solve_contact_ik.py`
  - `tests/test_contact_ik.py`（foot_lift/foot_slide/penetration/IK 限位/非接触帧保持）
  - 扩展 `scripts/m2_summary.py` 的 contact/IK 报告。

### 2.5 边界

- 不要用 GT 接触去“修”T5（无 GT）；
- 不要为了召回把非接触脚压地；
- 不要把 IK 结果写成 MMD IK 轨；保持 23 轨 FK + IK off；
- 不要动手臂/上身，只修腿/root XZ。

## 3. M2.3：多视/深度/手臂先验（2D 的边界）

### 3.1 先做“多视上限”实验（合成）

- 合成三机位（front/3-4/side）是同一 GT 动作的同一 canonical 姿态；用三个相机 + 2D 关键点联合拟合**一个** canonical pose，共享 body_pose，允许每视角相机已知。
- 目的：测“如果深度可见，手臂能修到多好”；这是上限，不是生产单视角管线。
- 指标：手臂世界角、3D 位置、2D 重投影、局部角（注意 twist）、三视角一致性。
- 如果多视也修不动手臂 → 问题不是深度，而是前馈/先验/模型；如果多视能降 10°+，单视角需要深度/先验。

> **M2.3 实测（2026-10-25）：负结果。** 三视共享 + 固定 GVHMR 根，最好只降 **3.6°**（front 50.23 vs 单视 49.59，反而 +0.64；3/4 59.81；side 99.60）。原因：2D 方向对手臂深度只有 3–5° 信息；三视角的 GVHMR `global_orient` 误差 13/35/84°，共享同一局部姿态时约束互相矛盾；无约束共享需 61–65°/关节、5% 身高，被信任域拒绝。**结论：不要再往 2D 加项；多视要有效必须先联合估计每视角根/相机（bundle adjustment）。**

### 3.2 单视角（真实 T5）方案

- **深度先验**：DAv2/DA3 相对深度序（不用绝对深度）；约束上臂/前臂/手的前后关系（肘在躯干前/后、手在胸前/外侧）。
- **解剖手臂先验**：
  - 肘铰链（elbow hinge）：前臂只绕肘轴弯曲；
  - 肩关节限位/手臂平面：限制上臂“前伸 vs 侧展”的不合理组合；
  - 手腕/手方向弱先验。
- **运动先验/时序**：手臂 swing 的时序平滑；不要逐帧硬拟合。
- **信任域**：沿用 `refine_2d.py` 的常量 swing + 3D 位移门禁；新增深度序/arm prior 项后，先在小范围验证，再放宽。
- **目标**：front/3-4 手臂世界角再降 **≥10°**（front 52.9→≤42.9，3/4 63.4→≤53.4）；side 世界角含 yaw，不作为跨机位门禁；用 3D 位置/2D 中位/局部角一起判。
- 如果深度/先验仍不能降 10°，再进入结构后馈/目标约束；**不要先训网络**。

### 3.3 不要做

- 不要逐帧 2D 硬拟合（已证明 3D 更差）；
- 不要用 2D 像素下降冒充 3D 改善；
- 不要把侧面世界角当跨机位指标（单目 yaw 不可观测）；
- 不要只用局部角判断手臂（twist 分布差）；用世界角/3D 位置/2D。

## 7. 不要做什么

1. 不要把 2D 重投影默认开；strict no-worse 已证明它会用局部角/twist 换世界角，必须 opt-in。
2. 不要逐帧 2D 硬拟合；前视深度歧义会把比例/相机偏差吃进手臂。
3. 不要为接触召回压 root/脚高；用 leg IK + 接触门控，非接触帧保留抬脚。
4. 不要用侧面世界角/世界位置做跨机位门禁；单目 yaw 不可观测。
5. 不要用局部角单独证明手臂修好；看世界角/3D 位置/2D。
6. 不要现在训后馈网络；先做接触/腿 IK + 多视/深度/arm prior。
7. 不要写 D 链/helper 到 MMD VMD；渲染走继承骨 bake。
8. 不要把肘铰链投影/roll 修正当成世界角改善：它会让 geodesic 下降，但前臂 swing 变差、自交增加；M2.4 已实测拒绝。
9. 不要把胶囊穿透约束强推到 0：GT 自身有 ~0.2 unit 的接触，且推出方向常与 GT 误差正交/反向；约束只能修“不穿模”，不能提供深度该往哪走。
10. 不要把 **world-only** 的手臂改善当成姿态改善：M2.4b 已实测 3/4 world −13.8°/swing −14.5° 的同时 body-relative **+12.6°**、穿透/jerk 变差；3/4 的 chest/root 误差 51°。手臂主指标必须是 body-relative swing/3D，world 只报告。
