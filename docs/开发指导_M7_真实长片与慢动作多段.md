## 2. M7 目标

### 2.1 真实连续长片

- 用一段**连续、无内容硬切**的真人/长片测试（30–60 秒，1080p，固定或轻运动相机）；
- 一条命令跑完整管线；输出 53 轨 + IK off + 无 D/helper；
- 无 GT：QC 只做证书/稳定性/接触/回退/边界；**不声称精度数字**；
- 报告回退窗口数、段边界、脚滑、jerk、手/脸 fallback；
- 与 M5 拼接片对比：回退率是否下降、边界是否更稳定；
- 真实连续片是 M7 的验收对象；拼接片只作压力测试。

### 2.2 慢动作 + 多段

- `--slow-factor 0.25/0.5` 与 `--chunk-seconds` 同时可用；
- 每个源段按 slow_factor 重映射到 30fps VMD 时间轴，段长/重叠按输出帧计算；
- 合并后帧数 = `round(src_frames / (30*src_fps?) * ...)` 按现有 M1 公式，统一到一个明确公式；
- 无重复/缺帧；段边界连续；脚滑/根/JERK 不突变；
- T1/T2 60 秒慢动作多段 smoke：0.25/0.5 各一次；
- 不再“明确拒绝”；若某些 slow_factor 不支持，给清晰错误和替代方案，而不是静默。

### 2.3 缓存重基线

- 代码冻结后（本阶段结束前不再改 `src/` 指纹相关代码），跑一次完整 run；
- 同命令第二次应 **全 cached**；记录耗时；
- 删除某段 `final.vmd` 后只重跑该段；
- 如果代码指纹仍导致全失效，修缓存键（区分“代码语义变更”和“无关键改动”），
  但不要用假缓存绕过正确失效；
- 明确记录“代码改动后第一次必重跑”的预期行为。

### 2.4 取景 margin

- `si after` 的 `within_margin=false` 要修：增大 margin 或按 after bbox 重新拟合；
- 三模型 before/after 都满足 `framing_ok=true` **且** `within_margin=true`；
- before/after 同相机；人物完整入画优先，允许人物变小；
- 不改变动作/VMD。

### 2.5 段间轨迹（按需）

- 真实连续片如果出现跨段根/朝向漂移，再做跨段平滑/BA；
- 先测量，不预先上复杂 BA；若 yaw+平移对齐足够，记录并跳过。
