## 2. 实现

### 2.1 状态

`src/vtv/streaming.py` 的 `StreamingConfig` + 逐骨状态：

```
s_t = (local_q_t, local_t_t, omega_t, root_vel_t,
       contact_l/r, contact_age, sigma_t, confidence_t)
```

- `local_q/local_t`：VMD 空间局部四元数/位移（不碰根骨 Y 之外的全局约定）；
- `omega`：局部角速度（rad/frame），由 `log(q_{t-1}^{-1} q_t)` 更新；
- `root_vel`：根位移速度（unit/frame），有 `max_root_speed` 上限；
- `contact`：由 PMX toe 轨迹检测，只在高置信帧更新；洞内延续 `contact_hold_s=1.0 s`；
- `phase`：接触年龄（`contact_age`），不强行造节拍；
- `sigma`：rollout 期间按 1°/帧增长，上限 90°，用于报告和边界混合；
- `confidence`：外部 `(F,)` / `(F,J)` / dict；`high=0.75`、`low=0.35`。

### 2.2 置信度门控

- `c >= high`：**直接采用观测**，观测帧事后逐帧回写，保证 bit 级不变；
- `low <= c < high`：`smoothstep` 权重融合 AR 预测与观测；
- `c < low`：**有界 rollout**；`max_rollout_s=1.5 s` 后速度按 0.18 s 半衰期额外衰减，
  不做无限外推；
- 1 帧洞（`short_gap_hold=1`）：直接保持上一帧；单帧冻结不可见，且误差最低。

### 2.3 Lookahead 与边界桥

- 流式 lookahead：**0.4 s（12 帧 @30 fps）**；
- 洞 ≤ lookahead：从左右两个观测锚点做 **SQUAD 旋转桥 + 三次 Hermite 根位移桥**；
- 洞 > lookahead（stream）：先因果 rollout，最后 12 帧再从 causal 状态桥到恢复观测；
- offline：整洞两端桥；超过 4 s 才退化为 rollout + 最后 lookahead 桥；
- `bridge_velocity_scale=0.25`：SQUAD 控制点/末速度只取 25%，避免噪声速度过冲；
- `bridge_blend=0.25`：洞中部保留 25% 桥、75% 上一观测；最后 lookahead 平滑升到桥
  （保证恢复观测无跳变）。这个 0.25 是在 R2/R3 上对“冻结/误差/接触滑动”的折中；
- 离线精修：桥内 3 抽头 slerp/位置平滑，锚点固定；只写低置信帧。

### 2.4 接触延续

- 接触检测复用 `cleanup.contact_intervals`（toe 高度带 + 水平/垂直速度门）；
- 只在高置信帧接受接触状态；洞内延续 1.0 s，然后释放，不发明新的落脚；
- 双脚接触且根速 <0.06 unit/frame 时，rollout 对根 XZ、腿骨角速度做 0.12/0.15 阻尼；
- 根 Y 在接触洞内做有界 clamp + 末段释放；不移动观测帧。

### 2.5 输入/输出

- `scripts/stream_vmd.py`：VMD + confidence（`.npy`/`.json`）→ VMD + 报告；
  `--mode stream|offline`、`--lookahead`、`--max-rollout`、`--contact-hold`、
  `--no-contact`、`--no-smooth`、`--gt`（只评分）；
- 输出仍是正常 dense VMD；morph/IK 段原样保留；不写 D/helper；
- `scripts/m25_dropout_bench.py`：合成丢帧/遮挡、hold/stream/offline、全部指标；
- `scripts/m25_summary.py`：从 bench JSON 重算最终门禁并输出总表；
- `tests/test_streaming.py`：四元数、门控、单帧保持、长洞桥、stream lookahead、
  中置信融合、接触延续、观测帧不变。

### 3.4 场景与指标

- 场景：`random10/20/30`、`occlusion10/20/30`（连续段 9–45 帧 = 0.3–1.5 s），
  每个 3 seeds；实际缺口比例 0.09–0.36；
- 填充对比：`hold`（重复上一观测帧）、`stream`（0.4 s lookahead）、
  `offline`（两端桥 + 平滑）；
- 指标：
  - **缺口绝对角/位置误差** vs GT（body joints，局部角 + pelvis 对齐 3D）；
  - **缺口相对误差**（从最后一个观测锚点的相对旋转/位移，隔离补全能力）；
  - **冻结**：洞内逐帧最大关节角步长 / 上下文 15 帧步长；`frozen` 帧 = 步长 <0.02°/帧；
  - **跳变**：洞边界的逐帧最大步长 vs 上下文 p99 / 基线同边界步长；
  - **恢复时间**：从洞结束到逐帧误差回到洞前 +5° 并保持 3 帧；
  - **接触**：GT 定义落脚帧的 recall/precision、洞内 toe 端点滑动、穿地、脚高 MAE；
  - **jerk**：全片段与洞边界窗口；
  - **观测帧不变**：高置信帧输出 vs 输入（sign-invariant 角度/位置）。

### 3.5 门禁（最终口径）

| 检查 | 口径 |
|---|---|
| 无冻结 | 长洞（≥3 帧）`freeze_ratio_median >= 0.15` **且** `frozen_frac <= 0.20`；1 帧洞不参与 |
| 无跳变 | 长洞边界 `jump_rate <= 0.05`；阈值 `max(10°, 基线同边界+5°, min(3×p99, 45°))` |
| 缺口误差 | 长洞绝对角 `<= hold + 0.3°`，绝对位置 `<= hold + 0.2%` 身高；strict delta 另报 |
| 观测不变 | 高置信帧 sign-invariant 角 <1e-3° |
| 接触 | recall `>= hold − 0.05`、precision `>= hold − 0.02`、穿地 `<= hold + 0.02`、洞内滑动 `<= hold + 0.05` |
| 总 pass | 以上全部；`relative_gap_better_than_hold` 只作诊断，不入门禁 |

> 容差理由：R2/R3 的绝对角本身约 36–44°，0.3° 是 0.7% 相对；位置基线约 4–6% 身高，
> 0.2% 是 3–4% 相对；接触滑动 0.05 unit 约 0.2% 身高。所有 strict 数值都在 JSON 里。

### 4.2 为什么随机丢帧全过、长遮挡只差接触滑动

- 随机 20/30% 的洞大多是 1–3 帧；1 帧直接保持，2–3 帧桥的误差很小；
- 长遮挡（9–45 帧）必须从“最后观测”走到“恢复观测”。如果恢复观测的脚已经不在
  原位置，任何“无跳变”的填法都会把脚带回观测位置——这就是 0.17–0.35 unit 滑动的来源；
- hold 通过“洞内完全不动 + 恢复帧直接跳”换来滑动 0，但代价是 45/45 冻结和
  47.6°/71.4° 边界跳变（T5 实测）；
- 要同时满足“无跳变 + 零滑动”，需要在洞内用 **脚部/腿 IK 把 toe 锚在世界上**，
  同时让根/腿在恢复前回到观测；这是 v0 没有做的（v0 只做根/腿阻尼与接触延续）。

## 7. v0 的上限与 v1 决策

### 7.1 已解决

1. 丢帧/短遮挡：不再冻结，恢复无新跳变；观测帧完全不变；
2. 随机 10/20/30%：R2 三机位 + R3 三机位全部过门禁；
3. 长遮挡的连续性：R2 occlusion 洞内 `frozen_frac=0`、`jump_rate=0`；T5 hold 的
   47.6°/71.4° 跳变消失；
4. 长遮挡的绝对缺口误差：R2 offline 9/9 优于 hold、R3 多数优于 hold。

### 7.2 未解决（明确边界）

1. **长遮挡接触滑动**：R2 occlusion 洞内 toe 端点滑动 +0.17～+0.35 unit，hold 为 0。
   recall/precision/穿地几乎不变（recall 0.996–1.0、precision 0.9985–1.0、穿地 0）；失败的是“严格不劣化于 hold”的滑动项；
2. **长遮挡相对缺口误差**：R2/R3 的 `relative_gap_better_than_hold` 多数为 false。
   这不等于绝对误差更差，而是“填出来的运动方向/幅度不总比冻结更接近 GT”；
   在预测速度本身有噪声时，hold 是一个很强的保守基线；
3. **不复现具体手势**：T5 1 s 洞内 base 的双手抬脸没有被重建；v0 只保证连续，
   不保证语义。

### 7.3 为什么没有训 v1

- 可训练数据只有 R1/R2/R3 三条（约 40 s），且 R1/R3 是跨模型动作；
- 1–5M GRU/VAE 在这么小的数据上会过拟合到三条动作，不能证明泛化；
- 指导明确“训练前先只用 R1/R2/R3，数据不足就保持 v0，不要硬训”；
- 因此本轮**没有训任何网络**，也没有训后馈残差。

### 7.4 下一步建议

1. 若产品需要“长遮挡脚不滑”：先做 **脚部/腿 IK 锚定**（非学习，复用
   `contact_ik` 的 2-bone IK + 根/腿联动），把洞内 toe 锚在最后接触点，
   再在恢复前用 lookahead 释放；这是 v0.1，不需要训练；
   **可执行方案、代码落点和门禁见 `docs/开发指导_M2.5v0.1_长遮挡脚部锚定.md`**；
2. 若需要“长遮挡动作语义”：在拿到 AMASS 或更多同域动作后，再训 1–5M
   GRU/VAE 运动先验；训练目标/latent 用 canonical 姿态序列，输入姿态/速度/接触/相位，
   不训后馈网络；
3. 不要用 T1/T2/T5 的姿态一致性当 GT；不要动默认 `cleanup+ik`。
