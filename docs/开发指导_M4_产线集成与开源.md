## 2. M4 目标

### 2.1 一条命令跑通

```
视频
 → GVHMR
 → adapter（每模型）
 → cleanup
 → contact/leg IK
 → M3 手/脸（L0–L3）
 → M3.5 保守后馈（默认）
 → VMD（23+30 轨 + morph + IK off）
 → 2K 渲染
 → QC/report
```

要求：

- 一条命令，输入视频 + 模型列表 + 输出目录；
- 默认启用 M3.5 保守档；`--feedback off|default|full` 可切换；
- 每个阶段有独立缓存/断点，失败可重跑该阶段；
- 不静默跳过任何阶段；失败要写清原因；
- 默认输出仍是 53 轨 + IK off + 无 D/helper + 手指位移 0。

### 2.2 三模型 2K

- T5 三模型（si/luoxi/tiflos）都出 VMD + 2K 静帧 + 短片；
- before/after 固定机位各一组：not only si；三模型都要；
- D 链 0/0、verify <2e-6、scale warning 0；
- 目检：无新穿模/抖动/脚滑/手指翻转；身体修正自然；
- QC 报告记录主指标 + 次要 trade-off + 警告。

### 2.3 开源准备

- CLI/配置/文档/安装脚本；
- 仓库从 private 转 public 前：LICENSE、NOTICE、THIRD_PARTY_NOTICES、
  MODEL_LICENSES、demo 素材/说明；
- 权重、SMPL-X、三套 PMX、R1–R3 VMD、T1–T5 视频、`third_party/`、`models/`、
  `outputs/`、venv、日志**不入库**；
- 不复制 GPL 代码；GVHMR/SMPL-X 非商业研究依赖要写清；
- 不泄露 token/账号/本机路径。

## 3. 集成设计

### 3.1 新模块

| 路径 | 内容 |
|---|---|
| `src/vtv/pipeline.py` | 阶段编排、配置、缓存/断点、manifest |
| `src/vtv/feedback_apply.py` | 加载 ckpt、构建证据特征、应用保守残差、证书 |
| `scripts/run_vtv.py` | 一条命令入口（视频→三模型 VMD/渲染/QC） |
| `scripts/qc_report.py` | 逐片 QC、主/次指标、警告、失败归因 |
| `configs/pipeline.json` | 默认反馈档、模型列表、渲染参数、缓存目录 |
| `tests/test_pipeline.py`、`tests/test_feedback_apply.py` | 端到端/证书/断点/回退 |

复用：`run_gvhmr.py`、`run_adapter.py`、`clean_vmd.py`、`solve_contact_ik.py`、
`run_hand.py`、`run_face.py`、`assemble_handface_vmd.py`、`feedback_data.py`、
`feedback_net.py`、`eval_helpers.py`、`m35_t5_eval.py` 的应用逻辑。

### 3.2 反馈应用顺序

```
身体 VMD（adapter + cleanup + contact IK）
  + M3 手/脸（53 轨 + morph）
  → M3.5 默认反馈：只改 torso/clavicle/upperarm/forearm（gain .85/.2）
  → 观测/手/脸/根/腿/脚不因反馈改变
  → 写最终 VMD
```

- 反馈只对 body 残差；手/脸/根/腿保持 M3/M2.2 输出；
- 网络输出有界；应用后重新 FK/校验；
- 不把 D/helper/手指位移写进 VMD；
- 逐模型用各自 evidence/profile；不要拿 si 的输出直接套 luoxi/tiflos。

### 3.3 默认与回退

- `--feedback default` 是产品默认（torso .85 / arm .2 / smooth 3）；
- `--feedback off` 回到 M3 输出，作为对照/回退；
- `--feedback full` 只作实验，不默认；
- 若某片段反馈导致 QC 失败（接触/穿透/时序/手指/morph），自动回退该片段到 off，
  并在 QC 标记原因；不要整片静默失败。

### 3.4 QC 指标

每个片段输出 JSON：

- 阶段版本/输入哈希/模型 profile/反馈配置；
- body-relative main、chest/upperarm/forearm、local angle；
- contact recall/slide/penetration/height；
- jerk/spike；
- **次要**：world angle、3D 位置（必须报告）；
- 手/脸：L0–L3 比例、手指/morph 步长；
- 渲染证书：D 链、verify、scale；
- warnings/errors/回退片段列表。

QC 门禁沿用 M3.5：task_gate + 接触/穿透/时序 + 手/脸不变；次要指标只报告，
但如果超出预设警告阈值（例如 world > +2° 或 position > +0.2%H），必须显式警告。
