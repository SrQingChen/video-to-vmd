## 二、M3：手/脸（到时选一个下载，不影响现在）

| 模块 | 候选 | 状态 | 说明 |
|---|---|---|---|
| 手部 | HaMeR / WiLoR / SMPLer-X 手分支 | ⏸ 未下载 | 择一；先核实许可；8GB 优先小模型 |

## 四、明确不需要准备

- **CUDA Toolkit**：v2 生产路径不用 nvdiffrast/pytorch3d 编译；不需要。
- **pytorch3d 真包**：用 shim；不需要 Linux wheel。
- **nvdiffrast**：只研究分支；不装。
- **QuickMagic 账号**：无商用、无硬基线；不需要。
- **reze-mipo 部署**：clone 已够参考；不需要重新部署 GUI。
- **T3/T4 新素材**：不是主验收；不需要。
- **DA3/RAFT/AMASS**：可选项；不需要现在下。

## 五、开源发布前（不是开发前）

- `LICENSE`（Apache-2.0）、`NOTICE`、`THIRD_PARTY_NOTICES.md`、`MODEL_LICENSES.md`；
- CC0/CC-BY demo 模型 + 自生成 demo 视频；
- 不提交：GVHMR/SMPL-X/权重、三套 PMX、R1-R3 VMD、T1-T5 视频、third_party 大文件；
- README 标注：research/non-commercial 默认；代码 Apache-2.0；商用需替换非商业 backend；
- 不复制 reze-mipo（GPL）代码；mmd2gltf（MIT）保留声明。

## 六、结论

- **现在就可以开工 M0**，不需要你再去下载任何**项目专用素材**；pip 依赖按 `docs/开发交接_新窗口.md` 安装即可。
- 唯一建议提前决定的是：M3 手部专家选 HaMeR 还是 WiLoR（或 SMPLer-X），以及脸部用 MediaPipe 还是 anime face；到 M3 再定也完全来得及。
- 如果你想让开源仓库一 clone 就能跑 demo，可以提前找一个 CC0/CC-BY 的 MMD 模型；不影响开发。
