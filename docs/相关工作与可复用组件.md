## 1. 可以直接借鉴/复用的组件

| 工作 | 可复用的部分 | 注意 |
|---|---|---|
| **GVHMR** | 单目视频 → 世界系 SMPL-X 动作，当前前馈主干 | 非商业研究许可；权重/body model 不入库 |
| **BEDLAM** | 合成视频 + GT 的生成/评测范式；可用于设计 VMD 闭环 QA | 数据集/权重许可见官方；不复制素材 |
| **SURREAL** | MoCap→SMPL→渲染→GT 的合成数据思路 | 只借方法，不引入其数据/模型 |
| **SMPLify / DenseRaC** | analysis-by-synthesis / render-and-compare 的损失设计 | 像素/剪影只适合同人/合成基准，不作跨身份主反馈 |
| **Neural Kinematic Networks** | FK 层 + cycle consistency 的无配对重定向思路 | 骨架是 SMPL/Mixamo，不是 PMX/VMD |
| **Skeleton-Aware Networks** | 不同骨架的共享隐空间/骨架池化 | 可借鉴 canonical 空间设计 |
| **TransMoMo** | 跨身份视频运动迁移、motion/structure/view 解耦 | 输出是视频，不是 VMD |
| **M-R²ET / R²ET** | 目标几何感知、穿模/接触缺失约束 | 脚滑不是其重点；骨架不是 PMX |
| **Contact-aware Retargeting** | 脚接触保持项、自接触/穿模约束 | 专利/论文；实现需自行写 |
| **ReConForM** | 高度损失 + 脚滑损失、实时接触感知重定向 | 可借鉴脚部约束设计 |
| **UnderPressure** | 脚接触检测 + IK 脚滑清理 | 压力鞋垫 GT 不可得；可用其思路 |
| **CycleAdapt** | 循环测试时适应/自监督反馈 | HMR 网络层，不是目标 PMX 约束 |
| **PyMAF** | 金字塔 mesh alignment feedback | 网络内部反馈，不是后处理 |
| **OpenMMD / Reze MiPo** | 视频→VMD 的工程经验、骨名/格式 | 许可见各自仓库；不复制 GPL 代码 |

## 2. 本项目自己必须做的部分

这些是已有工作没有直接给现成答案、需要在本项目里做对的：

1. **PMX/VMD 目标空间**：肩 P/C、腿 D 链、捩骨、IK、全角骨名、每模型 morph；
2. **目标模型 adapter**：rest pose、继承比例、骨长/体型、根轨迹、IK off；
3. **跨身份结构反馈**：不用像素/剪影，用 2D 关节、肢体方向、关节角、接触、时序、
   目标约束；
4. **VMD 合成闭环 QA**：GT VMD→PMX 渲染→GVHMR→adapter→VMD'→逐骨/接触/时序回归；
5. **长遮挡流式 + 支撑脚锚定**：VMD 层的缺口补全和脚滑修正；
6. **手部/表情**：手部专家 + L0–L3 置信度 + 每模型 morph 别名 + 自然 fallback；
7. **产品化**：CLI、缓存、断点、批处理、QC、安装文档、许可、demo。

## 3. 使用原则

- 已有工作当**已验证组件/基线**，不是“重复劳动”的威胁；
- 不在这些组件上重新发明；遇到问题先查它们的失败模式；
- 合成闭环用于**回归/验收**，不是论文式对照；
- 引用/许可要清楚：不复制代码/权重/素材，保留 NOTICE；
- 如果以后需要对外说明，写“built on established methods”并给链接即可。
