## 2. 目标与非目标

**目标**：长遮挡洞内，已检测到的支撑脚在世界上不滑；恢复观测时仍无新跳变；
观测帧不变；不冻结整段动作。

**非目标**：

- 不改善手臂、不碰 M2.4 系列；
- 不训练运动先验/后馈网络；
- 不改变默认 `cleanup+ik`；v0.1 是流式/离线补全的 opt-in 分支；
- 不为了让门禁通过而放宽阈值；
- 不动根骨 Y；不写 D/helper 到 MMD VMD。

---

## 3. 触发条件

只在同时满足以下条件时启用：

1. 连续低置信洞长度 ≥3 帧；
2. `estimate_contact` 的 `carried` 在洞前最后一帧为真（或洞内延续为真）；
3. 洞前是**高置信观测**，不是另一个洞；
4. 至少一侧脚在洞前最后 3 个高置信帧稳定接触（高度带内、水平速度低）。

一脚支撑可以锚定该脚；双脚支撑可锚定双脚。**不要**对摆动脚锚定；
不要在洞内发明新的落脚；`contact_hold_s` 到期后释放。

## 4. 算法

### 4.1 锚点

- `toe_anchor[x,z]` = 洞前最后 3 个高置信接触帧的 toe 世界 XZ 中位数；
- `toe_anchor[y]` = 地面高度（或洞前 toe Y 中位数），不把脚往下压；
- `foot_world_q` = 洞前最后观测的脚世界朝向；
- 锚点只来自低置信洞之前的观测，**绝不读洞内/GT 值**。

### 4.2 目标脚位

- 目标 toe 世界位置 = `(anchor.x, ground_y, anchor.z)`；
- 由脚世界朝向与 PMX rest 几何反算目标 ankle：
  `ankle_target = toe_target - R_foot · (toe_rest - ankle_rest)`；
- 这样修的是脚/腿链，不是把 toe 直接平移。

### 4.3 2-bone IK

- 链：hip → knee → ankle；脚 local/世界朝向保持；
- 在当前根/髋位置下解 2-bone IK；优先保持膝盖当前弯曲平面，避免膝盖翻转；
- 信任域：膝弯曲变化 ≤15°，大腿 ≤25°，单帧踝位移 ≤2.5% 身高；
- 不可达时（根走得太远/腿伸直）按可达性平滑降低锚定权重，不要硬拉；
- 根 XZ：双脚支撑且洞前根速低时，可沿用 v0 的 0.12 阻尼；单脚支撑时
  根继续按预测走，由腿 IK 追锚点。**根 Y 不动。**

### 4.4 释放

- 洞的最后 `lookahead`（0.4 s）内，把锚定权重从 1 平滑降到 0，
  与 v0 已有的 SQUAD/Hermite 桥/恢复观测混合；
- 用 `smoothstep` 保证位置和速度连续；释放段不能产生新的边界跳变；
- 恢复后的高置信帧逐帧回写，保持 bit 级不变。

### 4.5 与 v0 的顺序

建议在 `fill_vmd` 完成 v0 桥/rollout 之后、观测帧回写之前，做一次
**仅低置信洞内的 stance IK**：

```
v0 fill → stance anchor IK（仅洞内、仅支撑脚）→ 观测帧回写 → 输出
```

不要改 v0 的 `hold_short` 单帧洞；单帧洞没有可见滑动。

## 6. 评测与门禁

数据：R2 三机位 occlusion10/20/30 + random20/30；R3 三机位 occlusion；
T5 无 GT 视觉。GT 只读评分。

必须同时满足：

| 项 | 口径 |
|---|---|
| 脚滑 | 洞内 toe XZ 滑动 `<= hold + 0.05 unit`（目标 ≤0.05；不能只和基线比） |
| 连续性 | `frozen_frac <=0.20`、`freeze_ratio_median >=0.15`、`jump_rate <=0.05` |
| 缺口误差 | 长洞绝对角 `<= hold + 0.3°`、位置 `<= hold + 0.2%` 身高 |
| 观测不变 | 高置信帧 <1e-3° / <1e-6 unit |
| 接触 | recall/precision 不劣化、穿地不增加 |
| 回归 | random20/30 不掉；T5 不出现新冻结/跳变 |
| 渲染 | `render_synth.py` 继承骨 bake；D 链 0/0；VMD 23 轨 + 4 IK off |

如果锚定导致膝/腿不自然或恢复跳变，优先降低锚定权重/缩短保持时间，
**不要放宽脚滑阈值**。
