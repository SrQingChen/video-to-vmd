# M3.5 开发指导：数据引擎 + 自研后馈网络

> 日期：2026-10-27。工作目录：`E:\zcodeAI项目\视频转VMD`。
> 前置：M0–M2.5 v0.1 已完成；M3 手/表情完成后进入本阶段。
> 本轮目标：把“动作→视频→识别→VMD→和 GT 比对”的合成闭环变成**数据引擎/教师**，
> 训练一个低维、可解释、可流式的**自研后馈残差网络**；不是运动先验，也不是像素比对。
> 质量优先，RTF 不作门禁；离线允许小时级。

---

## 1. 当前状态与缺口

- 已完成的是**确定性结构后馈**：canonical/adapter、cleanup、2D opt-in、接触/腿 IK、
  流式 v0、支撑脚 IK v0.1；
- **学习式后馈网络尚未训练**；当前没有配对数据管线、没有网络、没有留出评测；
- 可用动作只有 R1/R2/R3（约 40 秒）；三套 PMX 可渲染；T5 无 GT；
- 8GB 显存；质量优先，训练/推理可以慢；
- 不要用 T5 训练/调参；T5 只做无 GT 视觉验收。

---

## 2. 合成闭环在 M3.5 的位置

这是本项目里“动作→视频→识别→动作比对纠正”真正变成**训练/纠正**的环节：

```
GT VMD（含手指/表情）
  → 三模型 PMX + 固定全身/手/脸机位渲染
  → 遮挡/丢帧/噪声/低分辨率增强
  → GVHMR → adapter → cleanup+ik → M3 手/表情
  → 与 GT VMD 逐骨/接触/时序比较
  → 低维残差目标
  → 训练后馈网络
```

关键边界：

- **训练/离线**：可以用 GT 计算残差、当教师；
- **推理/产品**：没有 GT，网络只能吃证据（2D、置信度、当前姿态、接触、目标 profile），
  不能读 GT、不能读原视频像素做比对；
- 合成闭环是 **development-time QA/teacher**，不是运行时输入；
- 不把像素/剪影损失当主目标；结构指标为主。

## 3. 数据引擎

### 3.1 数据源

- R1/R2/R3：主数据；三套模型（si/luoxi/tiflos）分别重定向；
- 可选 AMASS/CMU：只在许可允许、用户可获取时加入；不要用非官方镜像；
- 动作/模型/相机划分：
  - 训练：R1/R2 的多数片段 + 部分机位；
  - 留出：整段 R3、留出模型、留出机位；T5 只做视觉。
- 数据不足时先做**增强**（时间缩放、镜像、根 yaw、遮挡、丢帧、噪声、分辨率），
  但留出必须按动作/模型/机位整段划分，不能随机帧泄漏。

### 3.2 渲染

- 身体评估：固定全身前/3-4/侧机位（不用动作文件镜头 VMD）；
- 手/脸评估：额外固定近景手/脸机位，或高分辨率全身裁剪；
- GT VMD 必须包含手指/表情轨（R1/R2/R3 先检查；缺失则用程序化 GT 补单元测试，
  但正式指标只用有 GT 的轨道）；
- 渲染走 `render_synth.py`；D 链 bake 必须通过；记录相机内外参。

### 3.3 增强

- 随机丢帧/连续遮挡 0.3–1.5s；
- 2D 置信度降低/关键点抖动；
- 根轨迹短缺口；
- 相机轻微扰动、分辨率/压缩、光照变化（只用于训练泛化，评估用固定机位）；
- 不要改 GT 动作本身；增强只作用在观测侧。

### 3.4 配对数据 schema

每个 clip 保存一个 `.npz` + `.json`：

```
frames                 # 帧号
gt_canonical           # GT 姿态（body + fingers + morph）
pred_before            # 当前管线输出（cleanup+ik；M3 后含手/脸）
pred_after             # 若用确定性修正，记录 after
evidence_2d            # 2D 关节/手/脸关键点 + confidence
contact                # 脚/手接触状态
uncertainty            # 每帧/每骨置信度
target_profile         # 模型骨长/手指映射/morph 别名
camera                 # 内外参（训练/评估）
mask                   # 观测缺失 mask
split                  # train/val/test（按动作/模型/机位）
```

**禁止**把 `gt_canonical` 或原视频像素作为网络输入；只在 loss/teacher 中使用。

## 4. 教师与残差目标

### 4.1 教师

- 当前确定性管线（adapter/cleanup/contact IK/streaming/stance）作为**初始教师**；
- GT VMD 提供残差监督；
- 不做像素/剪影教师；不做“用弱教师固化弱残差”；
- 如果确定性管线在某个动作上明显错误，先修规则/数据，不要直接让网络学错。

### 4.2 低维残差

按可解释因子输出，不直接回归 53 骨四元数：

- 根：XZ 位移修正、Y 不修；
- 脊柱：spine/spine1/chest 的 swing/roll；
- 四肢：上臂/前臂/大腿/小腿 swing/roll；
- 接触：脚/手接触状态与脚踝修正；
- 手：每指屈曲/侧摆（M3 后）；
- 脸：morph 权重（M3 后）；
- 每维有界（例如 ±10–15°，根 ±0.1 unit），输出用 tanh/限幅。

**手/脸监督边界**：只对 M3 的 L0/L1 可见帧或合成 GT（近景渲染）计算手/脸残差；
L2/L3 fallback 帧不作为监督目标，否则网络会学会“默认微屈/中性”而不是恢复真实动作。
T5 手部 L0/L1 只有 8.3%/1.7%，不要指望 M3.5 从这些帧学会高保真手指；
需要更多手部数据时，用合成手/近景渲染，或换 MANO 专家，不要放宽 L0/L1 门控。

## 5. 网络

### 5.1 Baseline

- 先做 **per-factor MLP/GRU**（不是大 Transformer）：
  - 输入窗口 15–31 帧；
  - 输入：当前姿态、速度、2D 证据/置信度、接触、不确定性、目标 profile；
  - 输出：低维残差；
  - 1–5M 参数，8GB 足够；质量优先，可训练更久。
- 先离线双向窗口；稳定后再蒸馏/改成因果流式（lookahead 0.3–0.5s）。
- 不要把 v1 运动先验和这个反馈网络混在一起：v1 是缺口外推，M3.5 是残差纠正；
  两者可以共享数据，但输出/目标不同。

### 5.2 Loss

- 3D 关节位置/旋转（GT）；
- body-relative 上/前臂/chest（主指标）；
- 接触 recall/slide/penetration；
- 时序最大步长/jerk；
- 残差幅度/平滑正则；
- 手/脸：手指角/morph 权重（M3 后）；
- **不用像素/剪影**。

### 5.3 训练/推理

- 训练：按 clip 打乱，按动作/模型/机位留出；早停；
- 推理：无 GT；输入证据+当前输出；输出残差后重新走 FK/adapter；
- 失败退出：留出集没有稳定增益，就不默认启用；保留 `cleanup+ik`。

## 6. 评测与门禁

### 6.1 必须报告

- 留出动作/模型/机位：body-relative 上/前臂/chest、3D 位置、接触、时序/jerk；
- 与 `cleanup+ik` 基线逐项对比；
- 手/脸：手指角/morph 误差、L0–L3 覆盖率；
- T5 无 GT：视觉/fallback/人工检查；
- 数据泄漏检查：训练/留出无同段/同机位/同模型泄漏（按设计）。

### 6.2 通过条件

- 留出集身体指标稳定优于基线（至少主指标；不能只靠一个模型/一个机位）；
- 接触/穿透/时序不劣化；
- 手/脸不因后馈变差；
- T5 不出现新抖动/跳变/穿模；
- 消融：去掉网络回到基线，差异可解释；
- 不达标就不默认启用，继续用 `cleanup+ik`；不要用放宽门禁通过。

## 8. 不要做

1. 不要用 T5 训练/调参；T5 无 GT；
2. 不要把 GT 或像素放进推理输入；
3. 不要用像素/剪影当主 loss；
4. 不要直接回归全部骨骼四元数；先低维残差；
5. 不要用弱教师固化错误；教师不稳先修规则/数据；
6. 不要用随机帧划分造成泄漏；按动作/模型/机位留出；
7. 不要把手/脸 L2/L3 fallback 帧当监督；只用手/脸 L0/L1 或合成 GT；
8. 不要因为 RTF 牺牲质量；离线可小时级；
9. 不要在未过门禁时把网络设为默认；不要 commit 除非用户明确说。
