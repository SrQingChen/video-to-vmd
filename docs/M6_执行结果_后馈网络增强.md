## 3. M6.0 结论（摘要）

详见 `docs/M6.0_研究调研与benchmark.md`。

- **候选 A：GVHMR flip-TTA**：R3 三机位 raw main 37.72→34.91°（−2.81°），但单独仍差于 M3.5 27.38；T5 脚滑 +0.299。组合 M3.5 后三机位平均 28.95→25.87°，但 three_quarter +0.34°、position +0.08～0.25%H。**不作默认，只作 v2 可选上游/输入特征**。
- **候选 B：UnderPressure**：23 关节拓扑不匹配、本域预测几乎全程接触；F1 0.0399，与高度阈值基线相同。**不采用**。
- **不可运行候选**：MotionRefineNet（无权重）、HTD-Refine（AGPL + PVA-Net 权重在 Google Drive 不可达）、FootMR/ExMR（代码未发布）、SynSP/CycleAdapt/STRIDE（权重 Google Drive）、SMPLest-X（HF 8.2GB、8GB 不足）、PromptHMR（非商业 + 重依赖）、GMR（机器人 IK，不适用 PMX）。均记录原因，不伪造结果。
- **复用**：MRN 的时序-频域分支（v2 `arch=mrn`）；HTD 的“应用→重算→再预测”/接触联合思想（两轮实验）；FootMR 的“GVHMR + 残差”方向；GMR 的 rest-pose 对齐（adapter 已有）。

## 4. 数据扩展

### 4.1 网格与 split

| split | 段 | 帧 | 内容 |
|---|---:|---:|---|
| train | 58 | 18,430 | R1/R2 × {si,luoxi} × {front,three_quarter}：base 8 + occ/mix 16 + lowres/blur 16 + handgt 10 + facegt 8（含 2 段 front_left 的 handgt）；2 段 front_left base 已建但未用于最终 checkpoint（见 §4.2） |
| val | 10 | 3,155 | R1/R2 的 tiflos 和/或 side（整段留出模型/机位） |
| test | 9 | 4,860 | **R3** × 三模型 × 三机位（从未参与训练/调参） |

- train 帧数 **18,430 / 7,572 = 2.43×**；train 段 **58 / 24 = 2.42×**。
- 手 L0/L1：train **3,180 帧（两侧 6,361 side-frames）**，从 M3.5 的 462 帧扩到 6.9×。
- 脸：facegt 合成 L0 + 真实 facecam/face L1；`face_supported` 覆盖 blink/smile/mouth_a/i/u/e/o 等 9/12 语义通道（其余训练集无 GT，support mask=0）。
- R3 整段留出、tiflos/side 不在 train 的规则不变；`leakage_report` **ok**。

### 4.2 训练专用视角/观测

- `front_left`（az=−15°）：仅 R1/R2 × si/luoxi；2 段 base 已渲染/配对。R2 前左渲染的 YOLO 单人跟踪失败（无检测），**未纳入**，不伪造。2 段 R1 front_left base 并入 60 段重训后 R3 main 退化到 27.22°，因此**最终 checkpoint 仍用 58 段**；这两段文件保留，供后续视图泛化实验，不在 `outputs/m6/data/index.json`。
- `lowres`：0.45× 下采样 + JPEG 28 + σ=7 噪声；`blur`：GaussianBlur + JPEG 35 + σ=4；帧数/30fps 不变，GT 不动。
- `handgt`：GT 21 点手部 landmark + 3D 噪声 σ=4mm + 5% dropout，写成与 `run_hand.py` 相同的 `hand.npz`；只作训练证据。
- `facegt`：GT 12 语义 morph + 噪声 σ=0.05 + 5% dropout，写成 `face.npz`；只作训练证据。
- 增强/合成样本只监督对应流：lowres/blur 手/脸 mask=0；handgt 只监督手；facegt 只监督脸。

### 4.3 v2 特征

`feature_names(..., "v2")` 在 239 维基础上追加：

- 2×19 基线手角（`hand_base_*`）；
- 12 基线表情权重（`face_base_*`）；
- 合计 **289 维**。

原因：`handgt/facegt` 的“证据”是合成流，但残差目标必须相对**生产基线姿态**；不把基线放进输入，手/脸头会学成“预测 0 或凭空发明”。v1 checkpoint 的 239 维契约不变。

### 6.2 one-shot vs 2 轮 residual pass

| 配置 | R3 test main | chest | upperarm | forearm | world Δ | position Δ | hand |
|---|---:|---:|---:|---:|---:|---:|---:|

### 6.3 手/脸

- `hand-weight=1.0, face-weight=0.5, select=body`；v2 扩展模型 test hand MAE 46.72°；对输出行做真实 L0/L1 微调后 **46.06°**。
- M3.5 full 的 40.28° 仍更好；原因：M3.5 hand head 只在 462 真实 L0/L1 上训练，而 v2 合成手证据占多数，手头被“去噪/校正 fallback”主导。**full 不设默认**。
- face：合成 L0 + 真实 L1；test face MAE 0.2525（M3.5 0.2488），gate `face_not_worse` 通过（+0.02 容差）；T5 morph 步长不变。
- T5 full：finger p95 1.97→2.24（+13.7%，QC gate 通过；**不是“不变”**）；默认 v2 手/脸关闭，finger/morph **逐值不变**。

### 6.4 fallback 消融（重要）

M4 的 `_body_fallback` 在 v2 上过度屏蔽（arm-torso proxy + 5% jerk 窗口）：

| 配置 | R3 test applied | val applied | T5 |
|---|---:|---:|---|
| M4 fallback（proxy on, jerk 5%） | 25.59° | 29.38° | PASS（jerk +1.6%） |
| proxy off, jerk 5% | **24.59°** | 28.85° | **PASS**（jerk +1.6%） |
| proxy off, jerk 10% | 24.59° | 25.91° | **FAIL**（si +5.84%、tiflos +5.16%） |
| no fallback | 24.59° | 25.91° | FAIL（同上） |

v2 专用 `fallback_v2` = **proxy off + jerk 5% + slide/penetration + whole-clip fallback**。这样：
- R3 恢复 24.59°；
- T5 仍 PASS（jerk +1.61%，手指/morph 不变）；
- val 的 28.85° 是 jerk fallback 在留出 side/tiflos 上屏蔽窗口的结果，**如实报告，不隐藏**；no-fallback val 25.91° 作为网络内在精度一并报告。
- arm-torso proxy 仍在 QC `arm_penetration` 层报告，只是不再触发 v2 回退。

| fallback proxy off vs on | 24.59 vs 25.59 | proxy 是 v2 的主要精度损失源 |

**解释**：v2 的主要收益来自（1）更宽的肩链教师界（教师可达 0.06°），（2）基线手/脸特征与 289 维特征，（3）扩展数据/训练；手臂组从 −1～−2° 提升到 −3～−4°。2-pass 在侧视上过修正，没有稳定收益；根仍与 contact 冲突；手/脸合成数据没有超过 M3.5 的真实 L0/L1 手头。

## 10. 已知上限与失败模式

1. **手部 full 不如 M3.5**：v2 full hand MAE 46.06° vs M3.5 full 40.28°；合成手证据没有超过真实 L0/L1 手头。默认关闭；full 只作可评估/opt-in。
2. **T5 full 手指步长 +13.7%**：1.97→2.24，QC 通过但不是“不变”；默认 v2 手指/morph 逐值不变。
3. **val applied 28.85° vs no-fallback 25.91°**：jerk fallback 在留出 side/tiflos 屏蔽窗口；val 不是门禁，但这是真实的泛化/安全 trade-off，已报告。M3.5 val 27.11°；v2 no-fallback 25.91° 更好，applied 更差。
4. **2-pass 无稳定增益**：侧视过修正；保留 one-shot，不冒充闭环。
5. **fallback proxy 关闭**：v2 不再用 arm-torso proxy 触发回退，proxy 仍在 QC `arm_penetration` 报告；长视频/极端姿态需人工看 proxy。
6. **根/contact 仍冲突**：root+contact joint 的 slide +0.0361，根默认关。
7. **真实域**：训练/测试仍是合成渲染；T5 无 GT，只做稳定性/视觉。真实连续片留 M7。
8. **R2 前左视角 YOLO 失败**：只纳入 R1 两段 front_left，不伪造缺失数据。
9. **架构 applied 差异大**：TCN/MRN/Transformer/Graph 的 no-fallback 接近，但窗口回退后明显更差；BiGRU 的时序平滑性更适合生产 fallback。因果 GRU 25.99°，可作为流式候选，但离线默认仍是双向 BiGRU（24.59°）。
10. **没有 commit/公开**。
