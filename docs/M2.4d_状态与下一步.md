## 2. M2.4d 结论（负）

1. **Rig 映射精确**：`src/vtv/vposer_body.py` 用 per-joint D + stage yaw 180° + clip betas + NO_SWING
   把 PMX 姿态反推 SMPL-X body_pose：R2 front 躯干 0.000°、手臂 0.294°，随机闭环 2e-6°；
   torch/numpy 1.9e-15。漏 yaw 或 D 放错会留 15–77° 误差。**映射不是问题。**
2. **VPoser v2 在 R2 上与 GT 反相关**：KL 预测 **29.37** vs GT **133.78**；把 GT 手臂换进预测 →
   **127.26**（躯干 28.94、腿 33.31）。GT 的折叠手臂被 VPoser 判为低概率，先验不可能指向 GT。
3. **三条 VPoser 路径都失败**：
   - 先验-only（w=0.01）：上/前臂 **+11.17°**、chest 36.07°、penT 1.093 → fail；
   - 投影 `proj_torso`：上/前臂 **−0.42°**、chest 10.73°，但 penT 1.171 → fail；
   - joint torso+arms（无先验）：上/前臂 +1.89°、chest 27.78°、penT 0.523 → fail；
   - joint torso+arms + VPoser（0.03/0.1）：+12.71/+28.14°、chest 40.56/38.77° → fail；
   - arms + VPoser KL（0.03）：+13.10°、chest 11.16、penT 0.891 → fail；
   - arms + VPoser recon（0.01）：**−6.17°**、chest 11.16、penT 0.582 → **pass/ok**，但只是
     M2.4c arms BA 的水平，仍差 3.82° 到 10°。
4. **最佳过门禁候选仍是 M2.4c arms BA（无 VPoser）**：
   - body 上/前臂 24.07→17.89（**−6.18°**）；全 6 骨 35.89→26.33（−9.57°），其中手
     59.54→43.20（−16.34°）单独报告；
   - chest world 11.16 / chest in pelvis 17.01 不变；
   - 肘/腕 3D 11.10/11.58/12.45/11.71→6.26/6.80/5.79/6.31% 身高；
   - 臂-躯干 1.072→0.582、臂-臂 1.003→0；时序 31.76/17.41→23.86/16.62；jerk 3.1605→3.1549；
     接触/slide/穿地不变；
   - verify_ok=true、逐对预算全过；**accepted=false（上/前臂差 3.82°）**；只作 opt-in/多视上限。
5. **渲染证书通过**：`render_synth.py` 继承骨 bake，D 链 0/0、828 骨 max 1.062e-6、
   无 scale warning，stills 27/109/175/218/242。

**结论**：不是“VPoser 权重没调好”。无条件 VPoser 与 R2 的折叠手臂风格相反；2D/目标约束/
world 角/roll/BA 都已到边界。**继续调 VPoser/2D/约束不会到 10°。**

**建议顺序**：A（2–3 天）→ 如果无显著收益，C；B 只在 A 失败且要做研究时考虑。

## 4. 不要再做

1. 不要再调无条件 VPoser / 2D / world 角 / roll / 目标约束 / 肘铰链追 10°；
2. 不要用 strict 逐对穿透作唯一门禁（GT 自身违反 4 对）；用 `max(baseline,GT)+0.02` + 全局 max；
3. 不要先训后馈网络；不要把弱教师固化；
4. 不要默认打开 BA/prior/arm3d/约束/铰链；默认 cleanup+ik；
5. 不要用侧面/3-4 的 world 角跨机位；
6. 不要动根骨 Y 与 arm/IK 混在一起；髋高单独实验；
7. 不要为了 Blender 把 D 链写进 MMD VMD；渲染走 bake。

## 5. 门禁（固定）

- 手臂主指标：**body-relative 上/前臂/chest swing + 肘/腕 3D**；手单独报告；
- 碰撞：全局 max + `max(baseline, GT)+0.02` 逐对预算；strict 逐对只诊断；最终用 PMX 胶囊证书；
- 时序：max/p99 步长、jerk；
- world/geodesic 只报告；3/4/side world 不作跨机位；
- 不用 `summary_S`；不用 2D 像素下降冒充 3D。
