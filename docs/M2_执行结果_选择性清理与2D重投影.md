## 3. 选择性清理（F）

> 顺序说明：实现/验证按用户要求先做清理；最终组合管线的数据顺序是
> `npz → refine_2d → adapter → clean_vmd`。原因是清理作用在 VMD 空间、是最后一道视觉抛光；
> 若先清理再 2D，要把清理后的 VMD 重新 canonical 化再 adapt，纯属无谓往返。
> 归因不混：cleanup-only、2d-only、2d+cleanup 三组指标都单独列在 §5.1。

### 3.1 规则

1. **半球连续**：逐骨把四元数翻到与前一帧同半球，避免插值绕远路。
2. **孤立尖峰**：帧 `t` 与 `slerp(q[t-1], q[t+1], 0.5)` 的夹角 `dev` 超过**逐骨自适应阈值**
   `max(spike_deg, median(dev) + 8×MAD(dev))` 即 flag；连续 flag 形成 run，用 **run 前后最近
   未 flag 帧**做 slerp 桥接。run > 6 帧或桥接跨度 >120° 时只报告、不改（可能是真实快速发力）。
   合成 R2 的 `dev` 中位 0.65° → 有效阈值约 4°；T5 真舞中位 ~1.8°、MAD ~1.2° → 有效阈值
   11–12°，只 flag 4 帧。**绝对 4° 在 T5 上会 flag 331 帧并把 jerk 推高 10%，已废弃。**
3. **接触**：脚趾高度进入 `min(toe_y) + 0.02×height` 带，且水平速度 <0.12 unit/frame、
   垂直速度 <0.08 unit/frame；填 2 帧以内空洞、丢 3 帧以内孤岛，避免 contact flicker 驱动 root。
4. **脚锁**：只对 **接触比例 ≥0.8** 的脚、且区间净漂移 ≥0.5 unit 的区间生效；锚点取区间前 3 帧
   的中位 XZ；两只脚都可信时取平均；root XZ 修正做 5 帧平滑，总位移 cap 2 unit。
   **不强行压垂直高度**（`--vlock` 可选），避免把真实抬脚压成穿地。

每条都只改 flagged 帧/区间，没有全局滤波。清理后还有一个 **GT-free 自检**：
在 PMX 世界关节上计算 jerk RMS / MAD spike 数，要求
`jerk_after <= 1.02 × jerk_before` 或 `spike_after < spike_before`，否则报告
`WARN (over-smoothing?)`；T5 自适应后 16930→16773、spike 60→48，OK。

## 4. canonical 2D 重投影（非网络）

### 4.1 证据与坐标

- 2D：ViTPose COCO-17 全图像素（`preprocess/vitpose.pt`；新 npz 也含 `kp2d`）。
- 3D：GVHMR `smpl_params_incam` 已是相机坐标；用 `K_fullimg` 投影 SMPL-X COCO-17，
  肩/肘/膝/踝中位误差 **20–25 px**，手腕 **37–63 px**——2D 证据是准的。
- 用 `smpl_params_global` 直接投影会得到 z≈0 的世界坐标（GVHMR 的 global 是角色中心世界，
  不是相机深度），所以 2D 拟合只用 incam；`body_pose` 在 global/incam 两侧逐元素相同
  （R2 实测 max diff 0.0），修正后同时写回两侧，adapter 不受影响。

### 4.2 先做的负面实验（重要）

逐帧自由拟合（4 个手臂关节 × 3 轴，2D 位置残差 + 弱 3D 先验）在前视把 2D 手臂中位
**34.97→5.73 px**，但：

| front | 局部角 mean | 位置 mean | P99 | jerk× |
|---|---:|---:|---:|---:|
| baseline | 40.56 | 4.587 | 14.68 | 4.76 |
| 逐帧 2D 拟合 | **41.66** | 4.511 | **15.32** | **5.50** |

同时左臂 3D 方向变差、右臂略好。诊断：

- 前视上臂投影方向残差只有 **3–5°**，但 3D 上臂方向误差是 **19–25°**；2D 几乎看不出深度差。
- 2D 手腕误差主要是 **身体比例/相机尺度** 的系统偏差（投影前臂比关键点长 20–30%），
  逐帧拟合会把这些偏差吃进手臂旋转，等于拟合关键点噪声。
- 前视下手臂“前伸 vs 侧展”的差异在 2D 里高度退化；单视角 2D 无法可靠恢复。

所以最终实现改为 **整段常量 swing**（每个上臂 1 个 3 轴旋转，默认只修上臂；
`--joints both` 才加上前臂），并加速强 3D 先验和信任域；逐帧模式保留为 `--mode perframe`
但预期会被门禁拒绝。这个负面结果本身就是 M2 门禁的一部分：**不要用像素残差下降冒充 3D 改善**。

### 4.3 最终拟合与门禁

损失 = 置信度加权、bbox 归一化的鲁棒 2D 肘/腕位置残差
+ `λ3d` 手臂关节 3D 位移（相对 GVHMR 原姿态）
+ `λpose` 参数幅度 + `λtemp` 时域二阶差分。

默认：`--joints upper --mode const --lam3d 0.1 --lampose 0.01 --lamtemp 0.2`。

信任域（全部满足才写回；否则 npz 原样、`accepted:false`）：

- 2D 手臂中位误差改善 ≥5%；
- 单关节最大修正 ≤15°；
- 手臂关节平均 3D 位移 ≤2.5% 身高。

| view | 2D 中位 before→after | 改善 | 最大修正 | 3D 平均/最大位移 | 接受 |
|---|---:|---:|---:|---:|---|
| front | 34.97→23.06 px | 34.1% | 10.0° | 1.70% / 4.10% | 是 |
| three_quarter | 38.28→32.21 px | 15.9% | 7.3° | 1.28% / 2.77% | 是 |
| side | 53.95→49.82 px | 7.7% | 8.7° | 1.70% / 3.36% | 是 |

### 4.4 真实 T5（无姿态 GT）

- `refine_2d.py --npz outputs/gvhmr/T5/gvhmr_result.npz --joints upper` 信任域接受：
  2D 手臂中位 **36.58→27.65 px（−24.4%）**，最大修正 **5.9°**，3D 平均位移 1.22% 身高；
- 清理用自适应阈值只 flag **4 帧**（右ひじ 2、左ひじ 1、左手首 1），
  自检（世界关节 jerk）16930→16773、spike 60→48，OK；
- 全 828 骨 bake max **1.0e-6**、D 链 ok；stills
  `outputs/m2/render/t5_2d_clean_full/frames/{27,109,175,242}.png`；
- **没有 GT，不能声称 T5 姿态精度提升**；只能证明 2D 证据下降、清理自检不劣化、渲染无破坏。

- 位置均值不变差、位置 P99 不超过 baseline+0.5% 身高；
- jerk 不变差、滑动不超过 baseline+0.05；

`strict_failed` 分别是 front `[position_p99, angle_mean, angle_p99]`、

**因此 `refine_2d.py` 应作为 opt-in 阶段**：接受“手臂世界角/末端位置换一点局部角”的
Pareto 才开；要求所有分量单调不变差的场景不要开。真正的收益在：

- 位置均值 **−1.6%/−1.3%/−1.5%** 身高；
- 手臂世界角 **−3.5°/−2.2°/−2.2°**；
- 手臂位置（平均，unit）**−3.1%/−2.6%/−3.2%**；
- jerk **−39%/−12%/−6%**；侧面滑动 **−74%**。

### 5.2 为什么局部角会略升（不要误读）

M1.5 §4.5 已经记录：GT 用 捩/手捩 分担 twist，body-only 预测把扭转放在上臂/前臂，
所以**手臂局部角**是 twist 分布差，不是位置/末端朝向错。本轮 2D 修正只改上臂 swing，
手臂 **世界角**和 **3D 位置**都变好，但局部四元数在大角度 twist 下可能离 GT 更远。
因此门禁同时看：

- 非手臂局部角（2D 不动这些骨，理论上不变）；
- 手臂世界角（前视可信；侧面世界角含全局 yaw，**不能横比**，见 M1.5 §4.3）；
- 手臂 3D 位置；
- 位置均值/P99、jerk、接触/滑动。

不用 `summary_S` 排序，也不把侧面世界角放进跨机位门禁。

## 8. 已知问题与下一步

1. **接触召回没修**：0.46/0.70/0.98。预测脚整体偏高/偏低是前馈姿态与腿长问题；需要逐帧
   接触约束 + 2-bone leg IK，或者用多帧/多视约束，而不是压 root。本轮没有强行改，
   以免“看起来着地、实际脚在滑”。
2. **2D 深度歧义**：前视 2D 上臂方向残差 3–5°，3D 误差 19–25°；常量 swing 只能拉回 2–4°。
   下一步优先做**多视/相机先验**或**运动先验/深度序**，而不是逐帧 2D 硬拟合。
3. **结构后馈还没做**：本轮只在 canonical 的 body_pose 上做常量 swing，没有改目标模型约束
   （限位/twist/胶囊/穿地），也没有多轮微反馈。M2 的“后馈相对 M1 误差降 20–30%”还未达标。
