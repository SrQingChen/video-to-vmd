## 4. M3.5 的入口与已核对前提

### 4.1 GT 数据事实（重要）

| 文件 | 骨轨 | 手指 | morph | 说明 |
|---|---:|---|---:|---|
| `outputs/gt/si_R2_safe.vmd` | 58 | **含 30 指 + 手首** | **0** | 安全 GT（身体+手指），**没有表情** |
| `testdata/R2_王牌竞速/动作＋表情.vmd` | 913 | 含（60 指相关） | **12** | 原始动作+表情；含 D/helper 等 |
| `testdata/R3_花火主播/火花带表情.vmd` | 718 | 含（32 指相关） | **70** | 原始动作+表情 |
| `testdata/R1_妄想天使/动作.vmd` | 426 | 含（42 指相关） | **67** | 原始动作+表情 |

结论：

- **手指教师**：`si_R2_safe.vmd` 可直接用（30 指轨）；R1/R3 需先做同类安全 bake 或按 53 轨过滤。
- **表情教师**：`si_R2_safe.vmd` 没有 morph；必须从原始 VMD 取 12/70/67 条 morph 轨，
  或重新 bake 一份保留 morph 的安全 GT。**不要**把原始 913 轨直接当预测输入。
- 训练/评测只比较 23 身体 + 30 手指 + profile 实际存在的 morph；D/helper 轨不参与。

### 4.2 数据引擎（建议落点）

```
scripts/m35_data_engine.py
  --gt outputs/gt/si_R2_safe.vmd --motion-morphs testdata/R2.../动作＋表情.vmd
  --model si,luoxi,tiflos --views front,three_quarter,side
  --frames 0:249 --render-res 720x1280 --samples 8
  → render_synth.py（固定全身机位；手/脸近景可另加）
  → 增强（丢帧 0.3–1.5 s、2D 抖动/低置信、根短缺口、轻微相机扰动）
  → run_gvhmr.py（30fps 渲染视频；static_cam）
  → run_adapter.py（GVHMR → 目标模型）
  → clean_vmd.py → solve_contact_ik.py → run_hand.py/run_face.py + assemble
  → 与 GT 逐骨/接触/时序比较 → 保存 .npz + .json
```

必须遵守：

- 按 **动作/模型/机位整段** 划分 train/val/test；禁止随机帧泄漏。
- 推理输入只能是证据：当前姿态、速度、2D 关键点/置信度、接触、不确定性、目标 profile；
  **GT、原视频像素、GT morph 权重不得进输入**；GT 只在 loss/teacher。
- 渲染固定机位；不用动作文件镜头；`render_synth.py` 的 bake 证书必须 D 链 0/0。
- 增强只作用在观测侧，不改 GT 动作。

### 4.3 网络（建议落点）

```
src/vtv/feedback_data.py   # schema/残差目标/split/泄漏检查
src/vtv/feedback_net.py    # 1–5M MLP/GRU，有界低维残差
scripts/train_feedback.py  # 训练/早停/日志
scripts/eval_feedback.py   # 留出 vs cleanup+ik，门禁
tests/test_feedback_data.py、tests/test_feedback_net.py
```

输出因子（全部有界，tanh/限幅）：

- 根 XZ（Y 不修）；
- 脊柱 spine/spine1/chest 的 swing/roll；
- 四肢上臂/前臂/大腿/小腿 swing/roll；
- 接触状态/脚踝修正；
- 手：每指屈曲/侧摆（用 M3 的 19 角/侧，便于复用）；
- 脸：morph 权重（用 M3 的 12 语义通道）。

先离线双向窗口（15–31 帧），稳定后因果/流式（lookahead 0.3–0.5 s）。
教师 = 当前确定性管线（cleanup+ik + M3 手/脸）；GT 提供残差监督。
不要用像素/剪影作主 loss；不要直接回归 53 骨四元数。

### 4.4 M3.5 门禁（不达标不默认启用）
